# Paneli Production Hub — 31: Web ekrani na API-ju (ekrani 1–6, šifrarnik, postavke)

Stanje 16. 9. 2026. kasno navečer. Prvi radni ekrani Huba — po mockupu v0.4 (dizajn varijanta D: antracit zaglavlje, lijeva traka, papir /
mahovina / ABS plavo / MEL jantar), na postojećem API-ju, **bez okvira i bez builda** (`hub/web/index.html` + `app.css` + `app.js` + `ekrani.js`,
vanilla JS; servira ih isti FastAPI: `http://192.168.5.201:8766/`). **143 testa prolaze** (2 nova: ekrani se serviraju i registriraju; neuspjeh
Regal trake se pamti). Provjereno u pravom pregledniku (Chromium, 1440 × 980) na stvarnim podacima — HUMER kupčev PPW (5 materijala, 121 el),
Winstore XML, evidencija restlova — slike u `docs/ekrani_proba/`.

## 1. Ekrani

| # | Ruta | Što radi (sve preko API-ja) |
|---|---|---|
| 1 | `#/nalozi` | popis naloga s brojačima po statusu, pretraga, **Novi nalog** (pretraga kupca iz Pantheona / novi Hub kupac s provjerom ponavljača), **Corpus paket** (suho / uvezi) |
| 2 | `#/nalog/{id}` | **unos**: materijali (dodaj iz šifrarnika, uvoz CPW / CSV datoteke, put / god / restl / zadana traka), **element** (L, W, kom, naziv, napomena — Enter prihvati; klik na red = uređivanje, Esc = novi), **skica daske** koja prati mjere i okreće se kad je W dulji, kućice uz rubove (klik = aktivna traka, ponovni klik = makni, dvoklik u sredinu = sva četiri), **popis traka s oznakama** (A1, M1… — ABS-ISTI i MEL-ISTI zadano, `+ ABS` / `+ MEL` iz šifrarnika), tablica elemenata s rubovima (klik na kućicu mijenja rub odmah), **za potvrdu** (kandidati jednim klikom ili „drugi…“), zaglavlje naloga, status (dijalog „Kupac potvrdio“ za potvrđeno), Grupe (majke / sklopovi), Događaji |
| 3 | `#/nalog/{id}/obracun` | **obračun → ponuda**: stavke po grupama (materijali, rezanje, trake, kantiranje, usluge, okov) s pravilom uz svaku, neto / PDV / ukupno; **slaganje ploča** po materijalu: Hub prijedlog → alternativa (način × dubina) → **Potvrdi** (bez potvrde nema ponude ni izvoza); verzije ponude: nova verzija, PDF, **Pošalji kupcu** (mail), **Kupac potvrdio** (→ potvrđeno + eSlog), eSlog |
| 4 | `#/nalog/{id}/skladiste` | **provjera skladišta** po materijalu: treba / fizičko (Winstore kod) / rezervirano (drugi nalozi) / naručeno / raspoloživo / manjak, restlovi koji mogu poslužiti (klik = rezerviraj), trake s metrima na roli i pretincem; za nabavu; **restlovi iz shema** ovog naloga (Potvrdi s lokacijom / Nema ga, naljepnice PDF); Rezerviraj / Oslobodi / → Pila-nesting |
| 5 | `#/nalog/{id}/pila` | **pila / nesting**: put po materijalu, Hub pila vs bNest (ploče, iskorištenje, sheme PNG), slaganje s potvrdom, **izvoz** nesting / pila (pregled = suho, pošalji) / PanelWizard CPW s mapama, spajanje s drugim nalozima (prijedlog → spoji i izvezi), rezultat bNest `.mno`, krojni nacrt PDF |
| 6 | `#/nabava` | **potrebe** preko svih potvrđenih naloga (ploče i trake, manjak), **Narudžbenice iz potreba**; `#/nabava/narudzbenice` popis, `#/nabava/{id}` nacrt (stavke, količine, + stavka), Pošalji dobavljaču (PDF + mail), Zaprimi, Poništi, eSlog primka; `#/nabava/dobavljaci` e-mail po dobavljaču |
| — | `#/skladiste` | stanje po materijalu (Winstore + restlovi), `#/skladiste/restlovi` (filtri, novi restl, potvrda, otpis, naljepnice), `#/skladiste/potvrde` (57 dekora iz evidencije → ident jednim klikom) |
| — | `#/sifrarnik`, `#/postavke` | pretraga materijala / traka; postavke optimizacije i obračuna (kerf, nadmjera trake, obračun rezanja), e-pošta, korisnik |

Zaglavlje naloga nosi korake **1 Unos → 2 Ponuda → 3 Skladište → 4 Pila / nesting** (klik = taj ekran) i izbornik statusa. Korisnik je oznaka
(IVANA, GORAN, SANELA…) bez lozinke, pamti se u pregledniku — ide u sve zapise (tko je što napravio). Na ekranu nema oznaka odluka ni riječi „AI“;
poruke poslužitelja koje ih nose čiste se prije prikaza.

## 2. Pokretanje

**Port 8766** — 8765 je Knjiga ulaznih računa (KNJIGA.bat, firewall „Paneli - Knjiga 8765 (LAN)“), 8080 je Regal traka. Jednom na VM-u otvoriti port (kao za Knjigu, samo LAN):
`netsh advfirewall firewall add rule name="Paneli - Hub 8766 (LAN)" dir=in action=allow protocol=TCP localport=8766 remoteip=192.168.5.0/24`

```
cd /d C:\Users\Administrator\Desktop\IGOR\CLAUDE_COWORK\Paneli_Production_Hub\30_NOVI_PROGRAM
set HUB_DB=hub.db
py -m uvicorn hub.api.app:app --host 0.0.0.0 --port 8766
```
Zatim u pregledniku `http://192.168.5.201:8766/` (ili `http://localhost:8766/`). Fontovi Inter / IBM Plex Mono se učitavaju s interneta; bez njega
ekran radi sa sistemskim fontom.

## 3. Što je provjereno u pregledniku (Chromium, stvarni podaci)

Popis naloga → HUMER_OMIS_1 (5 materijala, 121 el / 278 kom, sve prepoznato) → unos elementa POLICA 1200 × 300 × 3 s trakom A1 na rubu preko
skice (Enter) → promjena ruba klikom na kućicu u tablici → obračun: Hub prijedlog slaganja (1 ploča), potvrda, nova verzija ponude v1 → **Kupac
potvrdio** → status potvrđeno → skladište: Winstore 13 ploča W908ST2-18, 2 restla iz evidencije (R0622 1995 × 995 kandidat), rezervacija, prijedlog
restla **R1364 2070 × 1574 iz sheme** → pila / nesting: pregled izvoza CPO (HUB_SUHO, 1 ploča) → nabava: potrebe 1 ploča, 8 m + 1 m trake.
Bez grešaka u konzoli. Nađeno i popravljeno usput: `GET /api/nalozi` vraća `{statusi, nalozi}` (ekran je čitao listu); neuspjeh Regal trake nije
se pamtio pa je ekran skladišta čekao 2 s po identu (sada 60 s keš i za neuspjeh).
